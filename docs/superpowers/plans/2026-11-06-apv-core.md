# apv_core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `apv_core`, a pure Python package that turns pre-computed district physics, crop parameters and finance inputs into a GCR sweep (0.00–0.50). For each GCR it produces low/central/high results for farm and energy income, yield retention against the draft policy limit, LER, KUSUM-A and lease finance, and notices.

**Architecture:** Small, focused modules with no file or network I/O: constants → crops → physics → retention → farm/LER → cash-flow primitives → business models → sweep. Every function is deterministic and works on numpy arrays or frozen dataclasses. The API (Phase 3) will wrap `run_sweep`. Tests use synthetic fixtures only.

**Tech Stack:** Python ≥ 3.11 (local 3.11.15; Vercel runtime 3.12), numpy ≥ 1.26, pytest, Hypothesis, ruff. No scipy and no pvlib, which keeps the Vercel bundle small.

**Spec:** [`docs/superpowers/specs/2026-11-06-agripv-lab-product-spec.md`](../specs/2026-11-06-agripv-lab-product-spec.md). Implements §12 (model), REQ-GCR-01/02, REQ-POL-01..04, REQ-RES-01/02, REQ-LER-01..03, REQ-FIN-01..06, REQ-CRP-01/03/04, and the `apv_core` part of §15.4.

## Global Constraints

- Package lives at `apv_core/` (repo root) with a src layout: `apv_core/src/apv_core/`, tests in `apv_core/tests/`.
- Pure functions: no file, network or environment access anywhere in `apv_core`.
- Runtime dependency: **numpy only**.
- GCR grid: exactly `(0.0, 0.05, 0.10, …, 0.50)`, 11 values, rounded to 2 dp. GCR 0.00 = open-field baseline.
- Acre = **4046.86 m²**. Analysis period = **25 years**.
- Season months (1 = January):
  - kharif = Jun–Oct `(6, 7, 8, 9, 10)`
  - rabi = Nov–Mar `(11, 12, 1, 2, 3)`
  - zaid = Mar–Jun `(3, 4, 5, 6)`
- Draft policy limit default **0.80**. Valid range 0.50–1.00.
- **Retention = `a_farm × Y_rel`, checked per season** (Q-02/Q-03 defaults). It is defined in exactly one function, `retention()`.
- KUSUM-A plant size range **0.5–2.0 MW**.
- Range spread default **±10%** on tariff and CAPEX. The pessimistic case pairs low tariff with high CAPEX and pessimistic crop parameters.
- `a_farm = 1.0` at GCR 0. APV cultivation-cost premium `p_apv` default **0.05**.
- Monetary values are ₹ per acre per year unless a name says otherwise.
- Never return NaN or inf: undefined results are `None` plus a reason string.
- The module for user-facing warnings is named `notices.py`, so it never shadows the standard library's `warnings`.

## Review Focus

1. **Rotation with fewer than three seasons** (e.g. kharif only, no zaid): weights, retention, LER and the allowed GCR must ignore missing seasons, not fail with KeyError or divide by zero. *Test: Task 5 `test_single_season_rotation_weights`, Task 8 `test_sweep_kharif_only`.*
2. **GCR 0.00 (no panels):** capacity 0, so IRR and payback are undefined, never a crash. LER must be exactly 1.0 and farm income exactly the baseline. *Test: Task 8 `test_gcr_zero_is_exact_baseline`.*
3. **Crops whose baseline cost exceeds revenue** (negative farm income, common in bad price years): the economic ratio becomes `None` and revenue weights still work. All-zero revenue raises `ValueError`. *Tests: Task 5 `test_economic_ratio_none_when_baseline_nonpositive`, `test_revenue_weights_zero_total_raises`.*
4. **Float noise in GCR and limit comparisons** (`0.1 + 0.2`, retention exactly 0.80): use index-based grids and a 1e-9 tolerance, so a retention of exactly 0.80 passes an 0.80 limit. *Test: Task 4 `test_allowed_gcr_exact_limit_passes`.*
5. **Unviable economics:** a target IRR above the project IRR gives a negative max lease, which must become `None` with "Not viable at target IRR". Zero or negative tariff or CAPEX inputs raise `ValueError` at construction. *Tests: Task 7 `test_max_lease_not_viable`, `test_finance_inputs_reject_nonpositive`.*

### Task 2: Ranges and crop shade response

**Files:**
- Create: `src/apv_core/ranges.py`, `src/apv_core/crops.py`, `tests/test_crops.py`

**Interfaces:**
- Consumes: `Season`, `SEASON_MONTHS` (Task 1)
- Produces:
  - `class Case(StrEnum)`: `PESSIMISTIC="pessimistic"`, `CENTRAL="central"`, `OPTIMISTIC="optimistic"`
  - `@dataclass(frozen=True) class Range`: `pessimistic: float | None`, `central: float | None`, `optimistic: float | None`; method `get(case: Case) -> float | None`
  - `class EvidenceGrade(StrEnum)`: `A`, `B`, `C`, `D`
  - `@dataclass(frozen=True) class CropParams`: `id: str`, `name: str`, `seasons: frozenset[Season]`, `tolerance: str` (one of "tolerant", "neutral", "sensitive"), `l_t: Range`, `k: Range`, `grade: EvidenceGrade`, `citations: tuple[str, ...] = ()`, `user_entered: bool = False`
  - `relative_yield(light: float | np.ndarray, l_t: float, k: float) -> np.ndarray`
  - `season_light(monthly_light: np.ndarray, season: Season) -> np.ndarray`, taking the mean over the season's months along the last axis (input shape `(…, 12)`; month m is index m-1)
  - `is_selectable_by_default(crop: CropParams) -> bool`: grade A, B or C
  - `needs_evidence_notice(crop: CropParams) -> bool`: grade C or D, or `user_entered`

`CropParams.__post_init__` raises `ValueError` unless:
- every `l_t` value is in (0, 1] and every `k` value is ≥ 0;
- the ordering is `l_t.pessimistic ≥ l_t.central ≥ l_t.optimistic` and `k.pessimistic ≥ k.central ≥ k.optimistic` (a pessimistic case never yields more);
- `seasons` is non-empty;
- `tolerance` is one of the three allowed values.

### Task 5: Farm income, LER and economic ratio

**Files:**
- Create: `src/apv_core/farm.py`, `src/apv_core/ler.py`, `tests/test_farm_ler.py`

**Interfaces:**
- Consumes: `Season` (Task 1); `CropParams` (Task 2)
- Produces:
  - `@dataclass(frozen=True) class CropEconomics`: `yield_q_per_acre: float`, `price_per_q: float`, `cost_per_acre: float`, `user_entered: bool = False`. Validation: yield ≥ 0, price ≥ 0, cost ≥ 0.
  - `@dataclass(frozen=True) class SeasonCrop`: `season: Season`, `crop: CropParams`, `economics: CropEconomics`. Validation: `season in crop.seasons`.
  - `baseline_income(econ: CropEconomics) -> float` = `Y * price - cost`
  - `season_farm_income(econ: CropEconomics, y_rel: np.ndarray, a_farm: np.ndarray | float, apv_cost_premium: float) -> np.ndarray` = `Y*y_rel*a_farm*price - cost*a_farm*(1+p)`. Where `a_farm == 1` and `y_rel == 1`, it must equal `baseline_income` exactly when `p` is applied only for GCR > 0. **The caller passes `p = 0` at GCR 0.**
  - `revenue_weights(rotation: Sequence[SeasonCrop]) -> dict[Season, float]`: shares of the baseline **gross** revenue `Y * price` (sum = 1). Raises `ValueError` on duplicate seasons or zero total gross revenue.
  - `energy_term(kwp_per_acre: np.ndarray, annual_kwh_per_kwp: np.ndarray, ref_energy_kwh_per_acre: float) -> np.ndarray`
  - `ler(weights: Mapping[Season, float], retention_by_season: Mapping[Season, np.ndarray], energy_term: np.ndarray) -> np.ndarray` = `Σ_s w_s * retention_s + energy_term`
  - `economic_ratio(farm_income: float, energy_income: float, baseline_farm_income: float) -> float | None`: `None` when `baseline_farm_income ≤ 0`

### Task 6: Cash-flow primitives

**Files:**
- Create: `src/apv_core/cashflow.py`, `tests/test_cashflow.py`

**Interfaces:**
- Produces (in every function, `flows[0]` is t = 0):
  - `npv(rate: float, flows: Sequence[float]) -> float`
  - `@dataclass(frozen=True) class IrrResult`: `value: float | None`, `reason: str | None`
  - `irr(flows: Sequence[float]) -> IrrResult`: bisection on `[-0.99, 10.0]` to `1e-10`.   - `annuity_payment(principal: float, rate: float, years: int) -> float`: level payment; `principal / years` when `rate == 0`

### Task 7: Business models — KUSUM-A, lease, max affordable lease

**Files:**
- Create: `src/apv_core/finance.py`, `tests/test_finance.py`

**Interfaces:**
- Consumes: `npv`, `irr`, `IrrResult`, `simple_payback`, `escalating_annuity_factor`, `annuity_payment` (Task 6); `Case` (Task 2); `ANALYSIS_YEARS` (Task 1)
- Produces:
  - `@dataclass(frozen=True) class FinanceInputs` (all per kWp or per acre, ₹):
    - `capex_per_kwp`, `om_per_kwp_year`, `om_escalation`, `tariff_per_kwh`
    - `degradation` (fraction/yr), `availability` (fraction)
    - `debt_share`, `interest_rate`, `loan_years`, `discount_rate`
    - `crop_inflation`, `lease_per_acre_year`, `lease_escalation`, `target_irr`
    - `years: int = ANALYSIS_YEARS`
    - Validation (`ValueError`): `capex_per_kwp > 0`, `tariff_per_kwh > 0`, `om_per_kwp_year ≥ 0`, `0 ≤ degradation < 0.05`, `0 < availability ≤ 1`, `0 ≤ debt_share ≤ 0.9`, `1 ≤ loan_years ≤ years`, `lease_per_acre_year ≥ 0`, all rates > -1.
  - `apply_case(f: FinanceInputs, case: Case, spread: float) -> FinanceInputs`: PESSIMISTIC → tariff × (1 − spread), CAPEX × (1 + spread); OPTIMISTIC → the reverse; CENTRAL → unchanged (`dataclasses.replace`)
  - `energy_series(kwh_per_kwp_year1: float, f: FinanceInputs) -> np.ndarray` (length `years`): `kwh * availability * (1 - degradation)^(t-1)`
  - `project_flows(kwp: float, kwh_per_kwp_year1: float, f: FinanceInputs) -> np.ndarray` (length `years + 1`): t0 = `-capex_per_kwp * kwp`; t ≥ 1 = `kwp * energy_t * tariff - kwp * om * (1+om_escalation)^(t-1)`
  - `@dataclass(frozen=True) class KusumAResult`: `project_irr: IrrResult`, `npv: float`, `payback_years: float | None`, `farmer_net_income_year1: float`
  - `kusum_a_per_acre(kwp: float, kwh_per_kwp_year1: float, farm_income_year1: float, f: FinanceInputs) -> KusumAResult`
    - Project IRR, NPV (at `discount_rate`) and payback come from `project_flows` (farm income excluded).
    - `farmer_net_income_year1` = farm income + year-1 project flow − year-1 debt service, where debt = `debt_share * capex * kwp` and service = `annuity_payment(debt, interest_rate, loan_years)`.
  - `@dataclass(frozen=True) class LeaseResult`: `developer_irr: IrrResult`, `farmer_income_year1: float`, `max_affordable_lease: float | None`, `max_lease_reason: str | None`
  - `max_affordable_lease(flows: np.ndarray, f: FinanceInputs) -> tuple[float | None, str | None]` = `npv(target_irr, flows) / escalating_annuity_factor(target_irr, lease_escalation, years)`. If ≤ 0, return `(None, "Not viable at target IRR")`.
  - `lease_per_acre(kwp: float, kwh_per_kwp_year1: float, farm_income_year1: float, f: FinanceInputs) -> LeaseResult`
    - Developer flows = project flows minus lease_t = `lease_per_acre_year * (1+lease_escalation)^(t-1)` for t ≥ 1.
    - `farmer_income_year1` = `lease_per_acre_year + farm_income_year1`.
  - With `kwp == 0`, every function returns `IrrResult(None, reason)` and `payback None`, and never raises.

**Files:**
- Create: `src/apv_core/notices.py`, `src/apv_core/sweep.py`, `tests/test_sweep.py`, `tests/test_properties.py`, `apv_core/README.md`
- Modify: `src/apv_core/__init__.py` (re-exports)

**Interfaces:**
- Consumes: everything above.
- Produces:
  - `class NoticeCode(StrEnum)`: `OUTSIDE_POLICY_LIMIT`, `NO_ALLOWED_GCR`, `LOW_EVIDENCE_CROP`, `USER_ENTERED_VALUES`, `KUSUM_SIZE_OUT_OF_RANGE`, `IRR_UNDEFINED`, `LEASE_NOT_VIABLE`
  - `@dataclass(frozen=True) class Notice`: `code: NoticeCode`, `message: str`, `gcr: float | None = None`
  - `class BusinessModel(StrEnum)`: `KUSUM_A="kusum_a"`, `LEASE="lease"`
  - `@dataclass(frozen=True) class SweepInputs`: `physics: PhysicsTable`, `structure: Structure`, `rotation: tuple[SeasonCrop, ...]`, `finance: FinanceInputs`, `business_model: BusinessModel`, `policy_limit: float = 0.80`, `apv_cost_premium: float = 0.05`, `land_acres: float | None = None`, `range_spread: float = 0.10`.   - `METRIC_KEYS: tuple[str, ...]`: `("farm_income", "energy_income", "total_income", "farmer_net_income", "ler", "energy_term", "economic_ratio", "kwp_per_acre", "energy_kwh_per_acre", "payback_years", "project_irr", "developer_irr", "max_affordable_lease")`
  - `@dataclass(frozen=True) class SweepResult`: `gcr: tuple[float, ...]`, `metrics: dict[str, tuple[Range, ...]]` (11 Ranges per key), `retention: dict[Season, tuple[Range, ...]]`, `outside_policy: tuple[bool, ...]` (central case), `allowed_gcr: Range`, `baseline_farm_income: float`, `notices: tuple[Notice, ...]`
  - `run_sweep(inputs: SweepInputs) -> SweepResult`

**How `run_sweep` works.** For each `case` in `Case`:
- Crop parameters `l_t.get(case)` and `k.get(case)`; finance `apply_case(finance, case, range_spread)`.
- Per GCR index i:
  - `L_s = season_light(light_fraction, s)`
  - `y_rel = relative_yield(L_s, l_t, k)`
  - `a = farmable_fraction(gcr, structure)`
  - `ret_s = retention(a, y_rel)`
  - farm income = Σ_s `season_farm_income(econ, y_rel, a, p)` with `p = 0` at GCR 0
  - `kwp = kwp_per_acre(gcr, efficiency)`; `kwh_yr1 = Σ_m E[i, m]`
  - energy income = year-1 project flow; total = farm + energy
  - `farmer_net_income` = `KusumAResult.farmer_net_income_year1` or `LeaseResult.farmer_income_year1`
  - LER via `ler(revenue_weights(rotation), …, energy_term(...))`; the energy term is also stored under `"energy_term"`, so per-season LER = `retention[s] + energy_term` (REQ-LER-03)
  - `project_irr` / `payback` from KUSUM-A in both models (the energy investment's own return)
  - `developer_irr` and `max_affordable_lease` only for LEASE (`None` for KUSUM-A)
- `Range(pessimistic, central, optimistic)` holds the case outputs, **not** sorted min/max.

**Notices:**
- `LOW_EVIDENCE_CROP`: once per crop where `needs_evidence_notice`
- `USER_ENTERED_VALUES`: if any crop or economics is user-entered
- `OUTSIDE_POLICY_LIMIT`: once, with the lowest offending GCR
- `NO_ALLOWED_GCR`: when the central `allowed_gcr` is None, message "No panel density in this range keeps {crop} at or above {limit:.0%} yield"
- `KUSUM_SIZE_OUT_OF_RANGE`: KUSUM-A only, when `land_acres` is given and `kwp * land_acres / 1000` is outside [0.5, 2.0] MW for any GCR > 0 (one notice, listing the first GCR)
- `IRR_UNDEFINED`: when the central project IRR is None at any GCR > 0
- `LEASE_NOT_VIABLE`: when the central max lease is None at any GCR > 0
